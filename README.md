# jutsumc-official-store
JutsuMC is an Anime x Minecraft Survival server inspired by popular anime worlds. Progress through ranks such as Shinobi, Sorcerer, Hashira, Jonin, Kage, Special Grade, and Uchiha while unlocking exclusive kits, crates, rewards, and unique features. Join events, KOTH battles, and a growing community on Java, Bedrock, and Cracked editions.
